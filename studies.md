## Task 1 — Classes, Objects and Constructors (25 minutes)

Watch the following videos on Classes and Constructors in Java:

- 📹 [Classes and Objects in Java — https://www.youtube.com/watch?v=Znmz_WxMxp4]
  

- 📹 [Constructors in Java — (https://www.youtube.com/watch?v=UC_aqNUFyVI)]
  - 
While watching, refer to **lesson.md Parts 1 and 2** and pay attention to:
- How a class is a blueprint for creating objects
- The difference between a class and an instance (object)
- How constructors initialize an object's attributes
- What constructor overloading means and why it is useful

**Guiding Questions:**
1. What is the difference between a class and an object?
2. What happens if you do not define a constructor in a class?
3. Why would you use an overloaded constructor instead of just one constructor?

## Task 2 — Encapsulation and the Static Keyword (25 minutes)

Watch the following videos on Encapsulation and Static members in Java:

- 📹 [Encapsulation in Java —(https://www.youtube.com/watch?v=YbqneqDIZh8)]
  

- 📹 [Static keyword in Java — (https://www.youtube.com/watch?v=7HYaQOyvw7Q)]


While watching, refer to **lesson.md Parts 3 and 4** and pay attention to:
- Why we make fields `private` and provide getters and setters
- The naming convention for getters and setters, including boolean fields
- The difference between instance members and static members
- When to use `static` and when not to

**Guiding Questions:**
1. Why is it considered good practice to keep fields `private`?
2. What is the naming convention for a getter method for a boolean field called `isMarried`?
3. What is the difference between calling a method on an instance vs calling it on the class name?

## Task 3 — POJOs and Records (20 minutes)

Watch the following videos on POJOs and Records in Java:

- 📹 [Java POJO explained — https://www.youtube.com/watch?v=oqPiEc2zNb0&t=153s]
  

- 📹 [Java Records — https://www.youtube.com/watch?v=gJ9DYC-jswo]
  

While watching, refer to **lesson.md Parts 6 and 7** and pay attention to:
- What a POJO is and what it is used for
- How a Record differs from a regular class
- Why Record fields are `private` and `final` by default
- How getter methods work differently in a Record vs a POJO

**Guiding Questions:**
1. What does POJO stand for and what is its main purpose?
2. Can you modify the fields of a Record after it is created? Why or why not?
3. What is one advantage of using a Record over a POJO for simple data objects?
